# PPT转视频项目结构分析报告

## 项目概览
PPT转视频项目是一个全栈应用，包含前端PPTist编辑器、后端Flask服务和VideoLingo技术融合模块。

## 📁 项目根目录结构

```
ppt_to_video/
├── 📁 前端模块
│   └── PPTist/                     # Vue.js前端编辑器
├── 📁 后端模块  
│   └── flask_backend/              # Flask后端服务
├── 📁 配置和部署
│   ├── config_data/                # 应用配置数据
│   ├── deploy/                     # 部署脚本
│   └── .vscode/                    # VS Code配置
├── 📁 文档和日志
│   ├── docs/                       # 项目文档
│   └── logs/                       # 运行日志
├── 📁 测试和输出
│   ├── tests/                      # 测试文件
│   ├── output/                     # 输出文件
│   ├── temp/                       # 临时文件
│   └── uploads/                    # 上传文件
├── 📁 开发环境
│   └── venv/                       # Python虚拟环境
└── 📄 配置文件
    ├── README.md                   # 项目说明
    ├── requirements.txt            # Python依赖
    ├── pyrightconfig.json          # Python类型检查配置
    └── PROJECT_STATUS.md           # 项目状态
```

### 主要功能模块
- **PPT编辑器**: 基于Fabric.js的演示文稿编辑
- **VideoLingo集成**: PPT转视频功能
- **配置管理**: 字幕、音频、导出配置
- **状态管理**: Pinia状态存储

### 核心功能模块
- **VideoLingo集成**: Phase 3技术融合完整实现
- **智能字幕**: 基于DP算法的字幕分割优化
- **配置管理**: SQLite存储的配置管理系统
- **TTS语音**: Edge TTS和Fish TTS支持
- **API服务**: 17个RESTful API端点
