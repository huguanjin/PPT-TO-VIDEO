## 🔧 技术架构

本项目采用前后端分离架构：

- **前端**: Vue3 + TypeScript + Vite + Element Plus
- **后端**: Flask + Python + Blueprint架构
- **AI集成**: VideoLingo + OpenAI + Edge TTS + Fish TTS
- **视频处理**: MoviePy + FFmpeg
- **字幕处理**: Netflix级别字幕引擎

详细架构说明请参考 **[项目结构分析报告](technical/项目结构分析报告.md)**
