## 🎯 清理执行计划

### Phase 1: 安全备份
```bash
# 创建清理前备份
git add .
git commit -m "项目清理前备份 - $(date)"
```

### Phase 2: 测试文件清理
```bash
# 删除根目录测试文件
rm test_*.py multilingual_demo.py
rm integration_test_report_*.json

# 删除后端测试文件
cd flask_backend
rm test_*.py demo_*.py *.mp4
rm -rf temp_test_project/ test_project/
```

### Phase 3: 缓存文件清理
```bash
# 清理Python缓存
find . -name "__pycache__" -type d -exec rm -rf {} +
find . -name "*.pyc" -delete

# 清理前端缓存 (可选)
cd PPTist
rm -rf node_modules/ dist/
```

### Phase 4: 备份文件清理
```bash
# 删除备份文件
find . -name "*.rar" -delete
find . -name "*备份*" -delete
find . -name "*backup*" -delete
```

### Phase 5: 临时文件清理
```bash
# 清空临时目录内容
rm -rf temp/* uploads/* output/*
```

### Phase 6: 文档整理
```bash
# 移动分散的文档到docs目录
mv PPTist/*.md docs/
mv flask_backend/*.md docs/
```

## 🚨 清理注意事项

### 安全措施
1. **Git提交**: 清理前必须提交当前状态
2. **分步执行**: 按阶段执行，每步验证
3. **功能测试**: 清理后测试核心功能
4. **备份重要**: 重要配置文件单独备份

### 风险评估
- **低风险**: 测试文件、缓存文件
- **中风险**: 临时文件、日志文件
- **高风险**: 配置文件、核心代码
