# 🎬 智能字幕功能使用指南

## 🚀 快速开始

### 1. 启动服务
```bash
# 进入项目目录
cd ppt_to_video

# 激活虚拟环境
.\venv\Scripts\activate

# 启动Flask后端
python flask_backend\app.py
```

### 2. 访问功能

#### 方式一：演示页面 (推荐)
直接打开 `智能字幕功能演示.html` 即可体验全部功能

#### 方式二：PPTist集成
1. 启动PPTist前端
2. 在编辑器顶部点击"字幕设置"按钮
3. 配置智能字幕参数

#### 方式三：API调用
```javascript
// 获取配置
fetch('http://127.0.0.1:5000/api/smart-subtitle/config')

// 测试分割
fetch('http://127.0.0.1:5000/api/smart-subtitle/test-split', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    text: "要分割的文本",
    config: { max_length: 75, smart_split: true }
  })
})
```

## ⚙️ 配置说明

### 基础配置
- **最大字符权重**: 控制每行字幕长度 (推荐75)
- **目标权重倍数**: 分割阈值倍数 (推荐1.2)
- **智能分割**: 启用语义和标点分割
- **AI分割**: 使用大模型语义理解

### AI配置 (可选)
- **服务类型**: OpenAI 或 Anthropic
- **API密钥**: 对应服务的API密钥
- **模型选择**: gpt-3.5-turbo 或 claude-3-haiku
- **自定义API**: 支持代理服务地址

## 🧪 功能测试

### 字符权重计算
输入任意文本，系统会计算：
- 总权重值
- 各语言字符权重分布
- 标点和空格权重

### 智能分割测试
输入长文本，系统会：
- 按权重智能断句
- 显示每行权重
- 提供分割质量分析
- 展示处理方法 (规则/AI)

## 💡 使用技巧

### 1. 权重配置建议
```
中文视频: max_length=75, target_multiplier=1.2
英文视频: max_length=60, target_multiplier=1.3
混合语言: max_length=70, target_multiplier=1.25
```

### 2. AI分割使用场景
- ✅ 长篇文章和专业内容
- ✅ 复杂语义和逻辑关系
- ✅ 对分割质量要求较高
- ❌ 简单短句 (浪费资源)

### 3. 性能优化
- 批量处理时关闭AI分割
- 相同配置重复使用
- 网络不稳定时使用规则分割

## 🔧 故障排除

### 后端连接失败
```
问题: 无法连接到127.0.0.1:5000
解决: 确保Flask服务正在运行
检查: python flask_backend\app.py
```

### AI分割失败
```
问题: AI分割返回错误
解决: 检查API密钥和网络连接
替代: 关闭AI分割使用规则分割
```

### 配置保存失败
```
问题: 配置无法保存
解决: 检查config_data目录权限
确认: 配置文件可写入
```

## 📊 质量指标

### 分割质量评估
- **均衡分布**: 各行权重差异较小
- **语义完整**: 不破坏语义单元
- **权重控制**: 每行权重不超过设定值
- **处理效率**: 分割速度和准确率

### 权重分布说明
- **均衡**: 各行权重分布均匀 ✅
- **中等**: 权重分布有一定差异 ⚠️
- **不均衡**: 权重分布差异较大 ❌

## 🎯 最佳实践

### 配置策略
1. **首次使用**: 使用默认推荐配置
2. **效果调优**: 根据实际效果微调参数
3. **场景适配**: 不同内容类型使用不同配置
4. **性能平衡**: AI功能按需启用

### 工作流程
1. **配置智能参数** → 根据内容设置权重和分割方式
2. **测试分割效果** → 使用测试功能验证效果
3. **调优配置参数** → 根据测试结果优化配置
4. **应用到生产** → 在实际项目中使用
