## 🚀 使用方法

### 立即生效
修改已完成，重启应用程序即可使用：

```bash
# 重启Flask后端
python flask_backend/app.py
```

### 样式选择
可以在配置中选择不同的Netflix样式：

1. **netflix_standard**: 标准样式（推荐）
2. **netflix_minimal**: 简约样式
3. **netflix_accessibility**: 无障碍样式

### 自定义配置
如需自定义，修改 `app_config.json` 中的 `subtitle` 节即可。
