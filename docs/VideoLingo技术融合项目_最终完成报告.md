## 📚 部署与使用指南

### 快速部署
```bash
# 1. 克隆项目
git clone <repository_url>

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动后端服务
python flask_backend/videolingo_integration_app.py

# 4. 访问系统
浏览器打开: http://localhost:8004

# 5. API测试
访问测试页面: http://localhost:8004/test/api
```

### 系统要求
- **操作系统**: Windows 10+, Ubuntu 18+, macOS 10.15+
- **Python版本**: 3.8+
- **内存要求**: 最低512MB，推荐1GB
- **存储空间**: 最低100MB，推荐1GB
- **网络要求**: HTTP/HTTPS访问支持

### 配置管理
- **环境变量**: 支持自定义配置
- **数据库**: SQLite无需额外配置
- **日志级别**: 可调节详细程度
- **端口设置**: 默认8004，可自定义
