### 1. Netflix字符权重计算器 V2
**文件**: `netflix_char_weight_calculator_v2.py`  
**功能**: 精确字符权重计算与36字符限制控制

#### 核心特性
- ✅ 中文字符权重系数: 1.75 (VideoLingo标准)
- ✅ 英文字符权重系数: 1.0
- ✅ Netflix 36字符有效限制
- ✅ 混合文本精确计算
- ✅ Unicode字符分类支持

#### 关键算法
```python
effective_chars = int(total_weight / 1.75)  # VideoLingo公式
netflix_compliant = effective_chars <= 36   # Netflix限制
```

#### 测试结果
- ✅ 中文字符权重计算: 100%准确
- ✅ 混合文本权重计算: 100%准确  
- ✅ 36字符限制验证: 100%准确
- ✅ 有效字符数计算: 100%准确

### 2. Netflix样式预设管理器 V2

#### 核心特性

- ✅ 黑色描边: `&H000000` 1px
- ✅ 5种预设配置 (standard, hd, large_text, high_contrast, videolingo_netflix)
- ✅ ASS/WebVTT格式生成

