# PPT转视频工具部署检查清单

## 📋 部署前准备检查

### 服务器环境
- [ ] Ubuntu Server 22.04 LTS 系统
- [ ] 最少4GB内存，推荐8GB+
- [ ] 最少20GB磁盘空间
- [ ] 2核心以上CPU
- [ ] 稳定的网络连接

### 域名和DNS
- [ ] 已购买域名并配置DNS解析
- [ ] 域名已解析到服务器IP地址
- [ ] （可选）准备SSL证书

### 本地准备
- [ ] 项目代码已完成开发和测试
- [ ] 已运行 `bash deploy/package.sh` 创建部署包
- [ ] 部署包已上传到服务器 `/tmp/` 目录

## 🚀 部署步骤检查

### 第一步：服务器基础环境
- [ ] 系统更新：`sudo apt update && sudo apt upgrade -y`
- [ ] 安装宝塔面板（如未安装）
- [ ] 登录宝塔面板并记录登录信息

### 第二步：安装项目依赖
- [ ] 运行：`sudo bash /tmp/ppt-to-video-deploy/install.sh`
- [ ] 确认安装过程无错误
- [ ] 检查项目目录：`ls -la /www/wwwroot/ppt-video/`

### 第三步：宝塔面板配置

#### 网站配置
- [ ] 创建网站
  - 域名：your-domain.com
  - 根目录：`/www/wwwroot/ppt-video/frontend/dist`
  - PHP版本：纯静态
- [ ] 配置Nginx
  - 复制 `config/nginx.conf` 内容
  - 替换 `your-domain.com` 为实际域名
  - 保存并重载配置

#### Python项目配置
- [ ] 进入Python项目管理器
- [ ] 添加项目
  - 项目名称：ppt-video-backend
  - 路径：`/www/wwwroot/ppt-video/backend`
  - Python版本：3.8+
  - 启动方式：Gunicorn
  - 启动文件：`flask_backend/app.py`
  - 端口：5000
- [ ] 启动Python项目

#### SSL证书配置（推荐）
- [ ] 申请Let's Encrypt免费证书
- [ ] 或上传自有SSL证书
- [ ] 强制HTTPS访问

### 第四步：功能测试
- [ ] 访问前端页面：`https://your-domain.com`
- [ ] 检查API健康：`https://your-domain.com/api/health`
- [ ] 测试文件上传功能
- [ ] 测试PPT解析功能
- [ ] 测试视频生成功能
