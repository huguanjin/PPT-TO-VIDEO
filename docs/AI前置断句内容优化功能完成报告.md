```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
```

### 工作流步骤

1. **step01_data_preparation**: 数据准备
2. **step01b_ai_content_optimization**: 🆕 AI内容优化 (可选)
3. **step02_tts_generation**: TTS生成 (支持分段)
4. **step03_video_generation**: 视频生成
5. **step04_subtitle_generation**: 字幕生成
6. **step05_final_merge**: 最终合成

### 数据结构转换

**输入格式** (原始scripts数据):
```json
{
  "scripts": [
    {
      "slide_number": 1,
      "script_content": "很长的文本内容，可能会导致多行字幕显示问题...",
      "word_count": 85
    }
  ]
}
```

**输出格式** (AI优化后):
```json
{
  "scripts": [
    {
      "page_num": 1,
      "original_content": "很长的文本内容，可能会导致多行字幕显示问题...",
      "segments": [
        {
          "content": "很长的文本内容，",
          "length": 15,
          "segment_id": 1
        },
        {
          "content": "可能会导致多行字幕显示问题",
          "length": 18,
          "segment_id": 2
        }
      ]
    }
  ]
}
```

## ⚙️ 配置说明

### 启用AI前置处理

在`app_config.json`中配置:
```json
{
  "ai_content_optimization": {
    "enabled": true,
    "max_segment_length": 35,
    "min_segment_length": 10,
    "preserve_meaning": true,
    "natural_breaks": true,
    "fallback_to_original": true
  },
  "ai_config": {
    "enabled": true,
    "service": "openai",
    "api_key": "your_api_key_here",
    "model": "gpt-3.5-turbo"
  }
}
```

### 前端配置

在视频导出时:
```javascript
const exportConfig = {
  ai_content_optimization: {
    enabled: true
  },
  // 其他配置...
}
```

### 1. 根本性解决方案
- **问题根源**: 原有方案在TTS生成后处理，只能重新分配时间
