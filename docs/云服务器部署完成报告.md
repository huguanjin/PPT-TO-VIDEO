# PPT转视频工具云服务器部署完成报告

## 📋 项目部署方案总结

### 项目架构
- **前端**: Vue.js + Vite (PPTist) - 静态文件部署
- **后端**: Flask API (flask_backend) - Python应用服务
- **服务器**: Ubuntu Server 22.04 LTS
- **面板**: 宝塔Linux面板
- **Web服务器**: Nginx
- **应用服务器**: Gunicorn
- **进程管理**: 宝塔Python项目管理器

### 部署包结构
```
ppt-to-video-deploy/
├── frontend/              # Vue.js构建后的静态文件
│   ├── index.html
│   ├── assets/
│   └── static/
├── backend/               # Flask后端应用
│   ├── flask_backend/     # 主要应用代码
│   ├── requirements.txt   # Python依赖
│   ├── gunicorn.conf.py   # Gunicorn配置
│   └── start.sh          # 启动脚本
├── config/               # 配置文件
│   ├── production.json    # 生产环境配置
│   ├── .env.template     # 环境变量模板
│   └── nginx.conf        # Nginx配置
├── install.sh            # 安装脚本
├── update.sh             # 更新脚本
└── README.md             # 部署说明
```

## 🚀 部署方式说明

### 方式一：一键部署（推荐）
```bash
# 1. 本地打包
bash deploy/package.sh

# 2. 上传到服务器并解压
scp ppt-to-video-deploy-*.tar.gz root@your-server:/tmp/
ssh root@your-server
cd /tmp && tar -xzf ppt-to-video-deploy-*.tar.gz

# 3. 运行一键部署脚本
sudo bash ppt-to-video-deploy/quick_deploy.sh
```

### 方式二：分步部署
```bash
# 1. 安装基础环境和宝塔面板
# 2. 运行安装脚本
sudo bash ppt-to-video-deploy/install.sh

# 3. 在宝塔面板中配置
# - 创建网站
# - 添加Python项目
# - 配置SSL证书
```

## 🚨 故障排除

### 常见问题
1. **视频生成失败** - 检查FFmpeg安装和权限
2. **内存不足** - 配置交换文件
3. **端口冲突** - 修改配置文件端口
4. **权限错误** - 检查文件和目录权限

### 调试方法
1. 查看应用日志: `tail -f /www/wwwlogs/ppt-video-app.log`
2. 检查进程状态: `ps aux | grep gunicorn`
3. 验证端口监听: `netstat -tlnp | grep :5000`
4. 运行健康检查: `/www/wwwroot/ppt-video/health_check.sh`
