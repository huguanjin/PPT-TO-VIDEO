# 后端工作流启动失败修复报告

## 问题描述
后端工作流执行失败，出现两个主要错误：
1. `'EnhancedWorkflowExecutor' object has no attribute 'start_workflow'`
2. `slides_metadata.json文件不存在`

## 问题分析
通过深入分析，发现了以下问题：

### 1. 相对导入问题
`flask_backend/core/step01_pptist_importer.py` 中使用了相对导入：
```python
from ..utils.logger import get_logger
from ..utils.file_manager import FileManager
```
当直接运行时，这种相对导入会失败，导致`EnhancedWorkflowExecutor`无法正常导入。

### 2. 路径操作问题
在`enhanced_workflow_executor.py`和`workflow_persistence.py`中，存在字符串路径和Path对象混合使用的问题：
```python
self.logger = get_logger(__name__, project_dir / "logs")  # project_dir是字符串时会报错
```

### 3. API数据类型问题
在`workflow.py`中，代码假设`execution.steps.get()`返回字典，但实际返回`WorkflowStepResult`对象：
```python
progress = execution.steps.get(current_step, {}).get('progress', 0.0) * 100  # 错误的用法
```

### 4. 数据准备步骤文件路径问题
工作流期望的是`slides/slides_metadata.json`文件，但PPTist导入器创建的是根目录下的`ppt_data.json`文件。

## 修复方案

### 1. 修复相对导入
将`step01_pptist_importer.py`中的相对导入改为绝对导入：
```python
# 修复前
from ..utils.logger import get_logger
from ..utils.file_manager import FileManager

# 修复后
from utils.logger import get_logger
from utils.file_manager import FileManager
```

### 2. 修复路径操作
确保在路径操作前将字符串转换为Path对象：
```python
# enhanced_workflow_executor.py
def __init__(self, project_dir: Path):
    self.project_dir = Path(project_dir)
    self.logger = get_logger(__name__, self.project_dir / "logs")  # 使用self.project_dir
    self.persistence_manager = WorkflowPersistenceManager(self.project_dir)

# workflow_persistence.py
def __init__(self, project_dir: Path):
    self.project_dir = Path(project_dir)
    self.logger = get_logger(__name__, self.project_dir / "logs")  # 使用self.project_dir
    self.workflow_dir = self.project_dir / "workflow_history"
```

### 3. 修复API数据类型问题
正确处理`WorkflowStepResult`对象：
```python
# 修复前
progress = execution.steps.get(current_step, {}).get('progress', 0.0) * 100
message = execution.steps.get(current_step, {}).get('message', f'{display_name}进行中...')

# 修复后
step_result = execution.steps.get(current_step)
if step_result:
    progress = step_result.progress * 100
    message = step_result.error_message if step_result.error_message else f'{display_name}进行中...'
else:
    progress = 0.0
    message = f'{display_name}进行中...'
```

### 4. 修复数据准备步骤文件路径问题
让数据准备步骤支持两种文件格式：
```python
# 优先检查slides_metadata.json，如果不存在则检查ppt_data.json
slides_metadata_path = self.project_dir / "slides" / "slides_metadata.json"
ppt_data_path = self.project_dir / "ppt_data.json"

slides_data = None

if slides_metadata_path.exists():
    # 使用slides_metadata.json
    self.logger.info("使用slides_metadata.json文件")
    import json
    with open(slides_metadata_path, 'r', encoding='utf-8') as f:
        slides_data = json.load(f)
elif ppt_data_path.exists():
    # 使用ppt_data.json
    self.logger.info("使用ppt_data.json文件")
    import json
    with open(ppt_data_path, 'r', encoding='utf-8') as f:
        slides_data = json.load(f)
else:
    raise Exception("找不到slides_metadata.json或ppt_data.json文件")
```

### 5. 增强fallback机制
为fallback的`EnhancedWorkflowExecutor`类添加`start_workflow`方法：
```python
class EnhancedWorkflowExecutor:
    def __init__(self, project_dir):
        self.project_dir = project_dir
    
    async def start_workflow(self, project_name, config=None, progress_callback=None):
        """Fallback implementation that raises an error"""
        raise ImportError("Enhanced workflow executor not available - core modules failed to import")
```
